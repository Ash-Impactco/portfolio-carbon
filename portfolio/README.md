# Aswin Raj Sivaprakash · Carbon project data portfolio

This is a static HTML, CSS and JavaScript site. It has no build step or runtime dependencies.

The work sample is an interactive example built entirely from fictional cookstove records and a fictional project area. It does not report real monitoring or removal results.

## Setup

- Save the CV as `Aswin_Sivaprakash_CV.pdf` in this directory to enable the Download CV link.
- Open `index.html` in a browser to preview the site.

## Deploy on Vercel

1. Push this repository to GitHub.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Set **Root Directory** to `portfolio`.
4. Choose **Other** as the framework preset. Leave the build command empty; there is no build step.
5. Deploy. Vercel serves `index.html` and the adjacent static assets directly.

For a CLI deployment, run `npx vercel` from this directory and follow the prompts. Use `npx vercel --prod` when you are ready to publish to production.
